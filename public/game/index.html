关于这个空间

谢谢你开车逛到这里。这个空间收录了我的公开项目、实验入口与联系方式。
更多日常笔记在 鏡花水月，源码与工具在 GitHub @ovws。

3D 基础

交互世界基于 Bruno Simon 的 Folio 2025（MIT）进行个性化改造，并使用 Three.js、TSL 与 Rapier 渲染和驱动物理效果。

我在折腾什么

自托管服务、Rime 输入法、AI 胶水层，以及把运维经验带进电商运营后的流程与内容实验。
当前常用入口集中在 qiwensong.com 与 blog.loser.dev。
