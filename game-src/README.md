# OVWS 3D portfolio source

This directory contains the editable game source for the deployed experience in `public/game`.

1. Copy `env.template` to `.env`.
2. Run `npm install` in this directory.
3. Run `npm run build` to update `public/game` without deleting the static 3D assets.

The game is personalized for 文山木公 / OVWS. It is based on Bruno Simon's [Folio 2025](https://github.com/brunosimon/folio-2025) and retains the upstream MIT license in `license.md`.
